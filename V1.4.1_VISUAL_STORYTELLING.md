# V1.4.1 — Visual Storytelling

## Goal
Move from “visually related” to “visually proves the narrated historical fact”.

### Pipeline
Research → visualizable facts → script + visual fact → visual intent → query → source → relevance → event specificity → information density → QA → AI reconstruction.

### New scene fields
- visual_fact: concrete historical fact that the frame should communicate.
- event_specificity: 0-1 score for how uniquely the visual belongs to the event.
- information_density: 0-1 score for how many concrete narrated facts are visible.

### Rules
- Generic atmosphere must not satisfy an evidence-bearing scene.
- Real sources are preferred, but only when they satisfy intent and event specificity.
- AI fallback must reconstruct the visual fact, not merely the narration keywords.
- Historical people must be represented by real archival material when available; otherwise clearly targeted historical reconstruction.
- A visual that could be reused for many unrelated historical events should score low on event specificity.
